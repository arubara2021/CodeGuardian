## Status
Complete. Passed isolation, chain, and regression.

## Files Written

## Purpose
Establishes the Python package identity and a single source of truth for
the version string, so every other module can import it without duplicating
the number.

## What the Test Proves
Both import paths (codeguardian.version and codeguardian.__version__) resolve
to the same string. get_version() returns the same value as the constant.
The inner pyproject.toml parses as valid TOML.
