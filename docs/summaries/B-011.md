## Purpose
Defines every error code CodeGuardian can raise, the category each code
belongs to, the retry policy attached to each category, and the base typed
exception used at every raise site.

## What the Test Proves
Every code is unique. Every code maps to exactly one category. Every
category has a retry policy. The retryable flag agrees with max_retries.
The lookup functions raise UnknownCodeError on garbage input rather than
returning None. CodeGuardianError copies the details dict at construction
so the caller cannot mutate it after raising. The translation layer
converts ten standard library exception types into typed errors with
correct codes, preserves the original exception as __cause__, and is
idempotent. The decorator works on both sync and async functions and does
not translate control-flow signals like CancelledError.

## Notes for the Next Block
The translation helper is a deviation from BUILD_ORDER. It was added
because the gap probe showed 12/12 leaks of standard library exceptions.
The helper lives in errors/translation.py and is exported from the
package. B-012 covers retry and redaction; it will consume the Backoff
enum and the RetryPolicy dataclass defined here.

The Rust workspace crates each carry a minimal Cargo.toml that declares
only a [package] section. The real crate contents arrive at B-063 and
B-070 through B-094. This minimal manifest exists so cargo metadata and
cargo fmt do not fail on an empty workspace member.
